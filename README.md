# Dotconsole

A responsive studio portfolio featuring Casually Social, TractionForge, FeatureLogs, and WordLine. Built with Next.js, React, TypeScript, and Tailwind CSS.

Requires Node.js 22.14 or later.

```sh
npm ci
npm run dev
```

Run `npm run lint` and `npm run build` before publishing. The production build exports the website to `out/` for static hosting. Contact links open an email to info@dotconsole.net.

Product icons are stored in `public/products/`. The first three come from their respective product websites; WordLine uses a temporary document symbol until its official artwork is available.
